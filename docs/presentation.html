05 Signals

What Should We Observe?

①SYSTEM

FastAPI request latency · SQLite write path · SSE connection health

the world your dashboards already own — this axis never changed for agents

②LLM

940 tokens/claim · 4.9s p50 · qwen2.5:7b local, $0/call

local inference makes cost a non-issue here — latency is the real budget

③AGENT

which MCP tool fired · sequence order held · one Langfuse session per claim

the control loop is the application now — a wrong tool choice is a bug, not a stack trace

④QUALITY

decision_correct score · groundedness 0-1 · 4/4 eval dataset pass rate

the layer everyone forgets — a claim can look "done" and still be wrong

The System Every Layer Watches
Langfuse is more than tracing here — Sessions group a claim's whole pipeline into one timeline instead of three disconnected traces. Users attribute LLM spend per patient, not just per app. Datasets + Scores turn "we fixed a bug" into "4/4 green," not a shrug. One honest caveat: the groundedness judge is app-managed, not Langfuse's native evaluator-rule engine — that migration is a known follow-up, not a finished feature.
core ▸ five layers, open standards at the seams — MCP for tools, Langfuse for the rest.
